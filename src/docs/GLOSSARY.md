# Glossary

| Term | Means | Not |
| --- | --- | --- |
| Item | One registered project buffer (file or in-memory document) | file, tab, entry |
| Layout | A `Window` or `View` block with `Control` children in a `.bui` item | form, screen |
| Control | One `Control` block inside a layout | widget, element |
| Navigator | Left pane: Filter, Project outline, Library | sidebar, tree |
| Library | Controls the catalog can design (built-in and discovered packages) | palette, toolbox |
| Design / Source | The two views of an item: WYSIWYG canvas or text | Designer mode, code mode |
| Inspector | Frame and property fields beside the canvas | properties panel |
| Messages | Bottom pane listing what Studio did or refused | log, problems, console |
| Agent | Right pane: provider, transcript, composer, proposals | chat, assistant |
| Proposal | An agent's suggested change; applied only with Apply changes | patch, diff |
| Edited | Item has unsaved changes | dirty, modified |
| Revision | Monotonic version of an item's buffer | version number |
| Discover package controls | Read package design metadata for the project folder | scan, plugin load |
| Complete project | Every source that could reference a control is a registered buffer | open tabs |
| Search documentation | Search across every loaded documentation source | Find on page |
| Find on page | Find matching text in the open article, including code | Global search |
| Reserved words | Compiler-audited word index with syntax-reference links | A promise that every reserved construct is implemented |
| Copy link | Copy a stable page, heading, member, or line-range reference | Navigate to the target |
| Code references | Keyboard-accessible list of definitions used in a code block | Every token as a tab stop |
